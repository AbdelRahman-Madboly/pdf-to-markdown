# Changelog

## Unreleased

- CI workflow that runs the tests on every push, with Java for the real conversion and a virtual
  display for the window tests.
- README: a Status section and the CI notes.

## 1.0.0 - 2026-11-01

- Tests for the conversion pipeline: a tiny PDF is generated by hand and converted for real (skipped
  when Java is missing), plus mocked tests for argument passing and error messages.
- Window smoke tests: the Tk window is built hidden, the queue, log colours and output check are covered.
- Fixed: every log tick started one more UI polling loop, so the app polled more often the longer it ran.
- Fixed: the installer looked for its files in the current folder instead of its own folder.
- README rewritten for this machine, MIT license added.

## 0.1.0 - 2026-07-04

- First version: queue PDFs, convert them in one opendataloader-pdf call, optional image extraction,
  log panel, desktop and menu launchers.
